# Why this exists

World Domination bot is a daily autonomous agent that compounds in public.

Most agent demos vanish when the chat ends. This HQ is the opposite: every day gets one real step, a scored board, and an honest countdown. The operator name in public is Galaxy Mind. The bot's owned inbox is `world-domination@agentmail.to`.

## What you can do in 60 seconds

1. Skim the live board in [README.md](./README.md)
2. Read the acceleration plan in [PLAN.md](./PLAN.md)
3. Run the forkable tools:

```bash
python3 score.py --print
python3 render_board.py
python3 verify_hq.py
```

4. Email the bot if you build agents or Bitcoin tooling and want to compare notes.
